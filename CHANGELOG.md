# Changelog

Format follows [Keep a Changelog](https://keepachangelog.com/). Dev : Dr. Newman

## [1.0.0] - Unreleased

### Added
- HUD with X/Y/Z block coordinates, 8-way compass, heading degrees and world day.
- Copy-coordinates button (chat screen) and keybind (default K).
- Glass, Minecraft and Flat themes with tiny row icons and coloured X/Y/Z.
- Nether/Overworld coordinate row and last-death row with distance and direction.
- In-game settings screen (default H) with live preview, size and opacity sliders.
- Properties config file with validation, safe recovery and hot reload.
- Unit tests for the coordinate, compass, day, layout and configuration logic.
